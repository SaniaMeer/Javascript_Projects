# JavaScript Projects

A collection of JavaScript projects built to practice and strengthen my understanding of **HTML, CSS, and JavaScript** through hands-on development.

Instead of only studying JavaScript concepts, this repository focuses on applying them by building small functional projects.

## Projects

### 1. To-Do List

A simple task management application where users can add and manage their tasks.

**Concepts practiced:**

* DOM Manipulation
* Event Handling
* Arrays
* Functions
* Local Storage

### 2. Digital Clock

A digital clock that displays the current time and updates dynamically.

**Concepts practiced:**

* Date Object
* `setInterval()`
* DOM Manipulation
* Functions

### 3. Calculator

A basic calculator for performing common arithmetic operations.

**Concepts practiced:**

* Functions
* Event Handling
* DOM Manipulation
* Operators
* User Input

### 4. Weather App

A weather application that fetches and displays weather information using a weather API.

**Concepts practiced:**

* Fetch API
* Promises
* Async/Await
* API Integration
* DOM Manipulation
* JSON

### 5. Quiz App

An interactive quiz application that displays questions and keeps track of the user's score.

**Concepts practiced:**

* Arrays and Objects
* DOM Manipulation
* Event Handling
* Conditional Statements
* Functions

### 6. Expense Tracker

A simple expense tracking application for recording income and expenses and calculating the current balance.

**Concepts practiced:**

* Arrays
* Objects
* Functions
* DOM Manipulation
* Event Handling
* Form Handling
* Array Methods

### 7. Movie Search App

A movie search application that uses the OMDb API to search for movies and display their details dynamically.

**Concepts practiced:**

* API Integration
* Fetch API
* Async/Await
* DOM Manipulation
* Event Handling
* JSON Data
* Dynamic Data Display


## Technologies Used

* HTML
